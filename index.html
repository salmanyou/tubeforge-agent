TUBE FORGE

YouTube growth console — SEO scoring, agent pipeline, real progress tracking

No channel connected — go to Setup
What this actually does: Tube Forge reads real public data from your channel through the official YouTube Data API, scores your titles/tags/descriptions with a transparent (non-black-box) heuristic, and uses AI to draft better versions. It tracks a real history snapshot every time you run it, so the Growth Console shows genuine before/after progress — not a simulation.

What it won't do: auto-like, auto-view, auto-comment, or auto-subscribe. Faking engagement metrics is manipulation and risks a strike — this tool never touches those.

This read-only dashboard uses an API key and never writes to your channel — everything here is copy-paste. If you want metadata changes actually applied for you around the clock, that's a separate piece: the Tube Forge Agent, a small backend script that logs in as you (real OAuth, your consent) and updates title/description/tags directly through YouTube's official write API — the same thing you'd do by hand in Studio, just automated, score-gated, and rate-limited so it never spam-edits a video. See the Autopilot tab for its live status, and the project README for setup.

01YouTube Data API key

Free, takes ~2 minutes, no billing required for this usage level.

  1. Open Google Cloud Console → YouTube Data API v3 and click Enable (create a project first if asked, any name).
  2. Go to APIs & Services → Credentials → Create Credentials → API key.
  3. Copy the key and paste it below. Optionally restrict it to "YouTube Data API v3" only (not by referrer, since this runs in a sandboxed viewer).
